Google Drive

Your questions are kept in one file, fitter-question-bank.json, in My Drive. A change is saved to Drive a few seconds after you make it, and your other devices pick it up within about 30 seconds. Everything is also kept on this device, so you can keep working offline.

Google Cloud setup (one time)
  1. In Google Cloud Console, create a project and turn on the Google Drive API under APIs & Services, then Library.
  2. Open OAuth consent screen, choose External, fill in the app name and your email, and add your own Google account as a test user.
  3. Open Credentials, choose Create credentials, then OAuth client ID, type Web application. Under Authorized JavaScript origins add this site’s address (no path, no trailing slash).
  4. Copy the client ID below and save it. To use it on every device, paste it into the GOOGLE_CLIENT_ID line at the top of index.html instead.

The client ID is set inside index.html.
